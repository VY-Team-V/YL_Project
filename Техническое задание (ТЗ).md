### Техническое задание (ТЗ)

##### Название проекта

* Personal Library Manager

##### Цель проекта

* Разработать веб-приложение для ведения персональной библиотеки, позволяющее пользователям управлять книгами: добавлять, редактировать, удалять, выдавать и возвращать.

##### Функциональные требования

###### 1\. Аутентификация и авторизация

* Регистрация и вход пользователей.
* Защита закрытых маршрутов.
* Хеширование паролей (bcrypt).
* Управление сессиями (Flask-Login).

###### 2\. Управление книгами

* Просмотр списка книг (только текущего пользователя).
* Добавление новой книги:

  * Название,
  * Год издания,
  * Автор (с выбором из существующих или созданием нового),
  * Жанр (аналогично).
* Загрузка обложки (PNG, JPG, JPEG).
* Редактирование и удаление книг.
* Фильтрация и сортировка книг.

###### 3\. Выдача и возврат книг

* Возможность выдать книгу читателю.
* Пометка книги как "выдана".
* Запрет на повторную выдачу до возврата.
* Возможность вернуть книгу.

###### 4\. API

* /api/books — возвращает JSON с книгами текущего пользователя.
* Обязательная авторизация.
* Валидация структуры ответа.

###### 5\. Интерфейс

* Адаптивный дизайн на основе Bootstrap.
* Карточки книг с обложками.
* Кнопки действий (Выдать, Вернуть, Редактировать, Удалить).
* Формы фильтрации и поиска.

###### Нефункциональные требования

* Безопасность: защита от SQL-инъекций, CSRF.
* Производительность: быстрая загрузка списка книг.
* Совместимость: поддержка современных браузеров.
* Тестируемость: покрытие API-тестами с pytest.

###### Технологии

* Backend: Flask
* ORM: SQLAlchemy
* База данных: SQLite
* Шаблоны: Jinja2
* Формы: Flask-WTF
* Аутентификация: Flask-Login + bcrypt
* CSS Framework: Bootstrap
